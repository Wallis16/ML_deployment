Text Generation
POST /generate

Request:

{
  "prompt": "Explain AWS ECS in one sentence",
  "max_new_tokens": 100,
  "temperature": 0.7
}

Response:

{
  "response": "AWS ECS is a managed container orchestration service...",
  "latency_ms": 245
}
Docker Strategy

Use an NVIDIA CUDA base image:

FROM nvidia/cuda:12.4.1-runtime-ubuntu22.04

Install:

torch
transformers
accelerate
fastapi
uvicorn

Run:

docker run --gpus all -p 8000:8000 smollm-api

Expected Deliverable for Part 1

By the end of Part 1, you should be able to:

curl -X POST http://localhost:8000/generate \
-H "Content-Type: application/json" \
-d '{
  "prompt":"What is AWS ECS?"
}'

and receive a valid response from SmolLM2-360M-Instruct running inside a GPU-enabled Docker container, with baseline performance metrics recorded for comparison after the AWS deployment.
